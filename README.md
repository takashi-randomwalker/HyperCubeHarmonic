# HyperCubeHarmonic and SphereHarmonic
This repository contains two notebooks of Wolfram Mathematica. They are a type of musical instrument designed by Maria Mannone and Takashi Yoshino.
- HyperCubeHarmonic.nb: A virtual program of a musical instrument based on the Rubik's cube in the four-dimensional space. 
- SphereHarmonic.nb: A virtual program of a musical instrument based on the C8 temari division on the spherical surface. 

A detailed description of the programs can be found in the following papers. 
1. Mannone, M., Yoshino, T., Chiu, P., & Kitamura, Y. (2022, June). Hypercube+ Rubik’s Cube+ Music= HyperCubeHarmonic. In International Conference on Mathematics and Computation in Music (pp. 240-252). Cham: Springer International Publishing. [Link](https://link.springer.com/chapter/10.1007/978-3-031-07015-0_20)
2. Mannone, M., & Yoshino, T. (2022). Temari Balls, Spheres, SphereHarmonic: From Japanese Folkcraft to Music. Algorithms, 15(8), 286. [Link](https://www.mdpi.com/1999-4893/15/8/286)
