2. Mannone, M., & Yoshino, T. (2022). Temari Balls, Spheres, SphereHarmonic: From Japanese Folkcraft to Music. Algorithms, 15(8), 286. [Link](https://www.mdpi.com/1999-4893/15/8/286)
